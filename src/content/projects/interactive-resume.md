## Overview

An interactive, game-based resume designed as an alternative way to present my portfolio and professional experience.

Instead of presenting information through a traditional resume layout, the project places my experience, education, skills, and projects inside an interactive 2D environment where users can explore and interact with different areas.

The project was built from scratch using JavaScript, with a custom engine created specifically to handle the game's core systems.

## Features

- Interactive 2D environment
- Player movement
- Keyboard and directional-button controls
- Interactive objects and areas
- Interactive resume sections
- Desktop and mobile controls
- Custom game engine
- Pixel-art inspired interface

## My Role

I independently designed and developed the entire project as an additional way to present my portfolio and technical skills.

I designed the interactive experience, implemented the game systems, created the custom JavaScript engine, and developed the resume content and interactions.

## Custom JavaScript Engine

One of the main goals of this project was to demonstrate my JavaScript knowledge by building a custom engine instead of relying on an existing game engine.

The engine handles the core systems required by the interactive resume, including player movement, input handling, object interaction, game states, and other gameplay-related logic.

## Design

The visual presentation uses a pixel-art inspired environment to make the resume feel more like an explorable game than a traditional portfolio.

Different areas of the environment represent different sections of my professional background, allowing users to discover information through interaction rather than simply scrolling through a page.

## Challenges

One of the main challenges was creating the underlying game systems without relying on an existing game engine.

I had to design and implement the systems responsible for player movement, input handling, object interaction, and the overall game loop while keeping the code organized enough to support additional interactive elements.

## Outcome

The result is a fully interactive resume that serves as an alternative presentation of my portfolio while demonstrating my JavaScript and game development skills.
