## Overview

A recreation of the classic Bow and Arrow game developed as part of my game development internship.

The project was created in Godot as an exercise in understanding the fundamentals of 2D game development and recreating an existing game's mechanics and gameplay experience.

## Features

- Bow and arrow shooting mechanics
- Player input handling
- 2D character and object animations
- Projectile movement and logic
- Collision detection
- Game state and gameplay logic
- Sprite-based 2D graphics

## My Role

I developed the game as part of my game development internship, where I was tasked with recreating the original Bow and Arrow game using Godot.

I implemented the gameplay mechanics, input handling, animations, and game logic. I also created some of the game's sprites using Aseprite.

## Development

The game was developed using Godot and GDScript. The project focused on implementing core 2D game development concepts, including player input, object interactions, animations, collision handling, and gameplay logic.

I also applied object-oriented programming concepts while structuring and implementing the game's systems.

## What I Learned

This project was an important introduction to more structured game development.

I gained hands-on experience with object-oriented programming and learned how to apply programming concepts to actual game systems. I also gained a better understanding of input handling, 2D animation, collision detection, game logic, and the overall workflow of developing a 2D game in Godot.

Creating some of the sprites in Aseprite also gave me experience working with the visual side of 2D game development.

## Outcome

The project successfully recreated the core gameplay experience of the original Bow and Arrow game and gave me practical experience in developing a complete 2D game using Godot.
